Before it can collect or forward any data, Factory Flow Gateway must be registered to your Factory Flow organization. Registration links the desktop app to a gateway record in the cloud, which is where you'll later assign machines to it.

## Getting a Gateway Token

Registration requires a **gateway token** — a string that starts with `gw_`.

1. Sign in to the Factory Flow web app.
2. Navigate to **Manage → Organization → Gateways**.
3. Create a new gateway (or open an existing one) and copy its token.

<Note>
  See [Gateways](/manage/organization/gateways) for how gateway records are created and managed in the web app.
</Note>

## Registering in the App

<Steps>
  <Step title="Open the registration screen">
    On first launch, Factory Flow Gateway will prompt you to enter your gateway token. To re-register later, click **Change/Update Settings** on the **Server Connection** card in Settings.
  </Step>
  <Step title="Enter your gateway token">
    Paste the `gw_` token you copied from the web app.
  </Step>
  <Step title="(Optional) Set a custom server URL">
    If you're connecting to a self-hosted Factory Flow deployment rather than the default cloud service, enter your organization's server URL.

    <Tip>
      If your self-hosted server's certificate was issued by an internal or private CA rather than a publicly trusted one, use the **CA Certificate (optional)** field to point the gateway at that CA's certificate so it can verify the connection. This is how gateways trust a server set up with [`./factoryflow cert`](/self-hosted/ssl-and-proxies#private-ca-for-lan-only-deployments) for a LAN-only deployment — run `./factoryflow cert export` on the server, transfer the resulting file to this machine, and select it here. Leave this blank when connecting to the standard Factory Flow cloud service or a self-hosted server with a publicly trusted certificate.
    </Tip>
  </Step>
  <Step title="Register">
    Click **Register**. The app validates your token against the server and, once successful, links itself to that gateway record.
  </Step>
</Steps>

## After Registration

Once registered, the **Server Connection** card at the top of Settings switches from the registration form to a live status view — connection status, your gateway's name, ID, assigned machines, masked token, and license status. See [Settings → Server Connection](/gateway/settings#server-connection) for the full field reference.

<Note>
  If you need to change which organization a gateway is registered to, rotate its token, or disconnect, click **Change/Update Settings** on the Server Connection card to reopen this form.
</Note>
