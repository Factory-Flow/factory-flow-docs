Factory Flow Gateway is built so that a flaky network connection or an app restart never means lost data.

## Local Queue First

Every data point the collector reads is saved to a **durable local queue** before anything is sent anywhere. If the network drops, or the app itself restarts, points already collected are safe on disk and will still be forwarded once things recover.

## Batching and Forwarding

Queued points are batched and forwarded to Factory Flow on a **configurable interval** rather than one at a time. If a forwarding attempt fails, the gateway retries with backoff rather than dropping the batch. Forwarding can optionally use **compression** to reduce bandwidth usage.

## Inspecting and Clearing the Queue

If you need to check how much data is pending, or clear it out, you can do so from **Settings → Collector**. See [Settings](/gateway/settings#collector-settings) for the related settings.
