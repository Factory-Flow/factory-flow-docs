## Collector Status

At the top of the dashboard, you'll see whether the collector is **running** or **stopped**, along with the elapsed time since it was started.

## Connections Overview

A breakdown of your active connections by status:

| Status | Meaning |
|--------|---------|
| **Connected** | The connection is established and healthy. |
| **Connecting** | The gateway is currently attempting to establish the connection. |
| **Disconnected** | The connection is not currently established. |
| **Error** | The connection failed and needs attention. |
| **Disabled** | The connection has been manually disabled. |

## Data Point Mappings

A summary of how many data point mappings you have configured, along with counts of points successfully **forwarded** versus **failed**.

## Recent Data & Metrics

The dashboard includes a live feed of recently collected data points, plus collector metrics:

- Points collected
- Points forwarded
- Points failed
- Success rate
- Data volume
- Average latency

These metrics can be viewed over a selectable time range, with a trend chart showing how they've changed over that period.
